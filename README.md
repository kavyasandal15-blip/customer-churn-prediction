# Customer Churn Prediction

A machine learning application that predicts whether a customer is likely to churn based on demographic and behavioral data.

## Features

* Customer churn prediction
* Data preprocessing and cleaning
* Exploratory Data Analysis (EDA)
* Machine learning model training and evaluation
* Web interface for real-time predictions

## Tech Stack

* Python
* Pandas
* NumPy
* Scikit-learn
* Flask
* HTML
* CSS

## Workflow

1. Load and preprocess customer data
2. Perform exploratory data analysis
3. Train and evaluate machine learning models
4. Generate churn predictions
5. Display results through a web interface

## Business Impact

The project helps identify customers at risk of leaving, enabling businesses to take proactive retention measures and improve customer retention strategies.
